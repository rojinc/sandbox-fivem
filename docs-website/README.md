# Sandbox RP Framework Documentation

Comprehensive documentation website for the Sandbox RP Framework v2.0, built with React + Vite.

## Features

- **Beautiful, Modern UI**: Soft colors and smooth animations for a premium documentation experience
- **Comprehensive Coverage**: Complete documentation for all 77 resources in the framework
- **Detailed API Reference**: Full API documentation with code examples
- **Developer Guide**: Step-by-step tutorials for creating custom resources
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Syntax Highlighting**: Code examples with beautiful syntax highlighting using Prism.js
- **Easy Navigation**: Intuitive sidebar navigation with organized categories
- **Search Functionality**: Quick search to find what you need

## Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Deployment

Build the production version:

```bash
npm run build
```

The `dist/` folder will contain the optimized static files ready for deployment.
